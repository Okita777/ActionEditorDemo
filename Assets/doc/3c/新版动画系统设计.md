# 新版动画系统设计

## 1. 目标

新版动画系统只负责表现，不参与状态裁决。

核心关系：

```text
StateController / StateTimeline
	└── 发起一次性动画命令
			└── CharacterAnimationController
					└── Animancer Layer
```

设计目标：

1. 状态决定何时请求播放、切换、停止动画。
2. 动画开始后由 Animancer 自己推进。
3. 动画不决定状态生命周期，不驱动命中、位移、打断或技能结束。
4. 状态常规 Tick 不持续控制动画时间。
5. 状态被打断时，新状态发起新的动画请求。
6. 高层动画只覆盖表现，不停止低层状态和低层动画。
7. Locomotion、Action、UpperBody、Additive 独立运行。
8. 时间恢复、回滚和编辑器拖动通过显式 Seek 处理，不做每帧同步。

## 2. 时间模型

### 2.1 双时钟

```text
Gameplay Clock
	State.ElapsedTime
	StateTimeline
	命中 / 位移 / 中断 / 技能流程

Presentation Clock
	AnimancerState.Time
	AnimancerState.Speed
	Fade / Layer Weight
```

两套时钟正常情况下独立推进。

```text
State Enter / Animation Track Trigger
	-> PlayAnimation(request)
	-> Animancer 自己播放

State Interrupt / Exit
	-> 新状态发起新请求
	-> 旧层按配置淡出或被同层动画替换
```

禁止常规每帧执行：

```csharp
animationState.Time = state.ElapsedTime;
```

### 2.2 显式 Seek

仅以下场景允许重新定位动画时间：

1. 状态以非零时间进入。
2. 存档恢复。
3. 网络快照校正。
4. Rollback 重演。
5. 编辑器 Timeline Scrub。
6. Animancer Graph 重建。
7. 动画控制权恢复。

```text
SeekTime = StateElapsedTime - TrackStartTime + AnimationStartOffset
```

Seek 是离散恢复命令，不是常规 Tick 行为。

## 3. Animancer 层模型

| Animancer Layer | 名称 | 混合方式 | AvatarMask | 默认权重 |
|---:|---|---|---|---:|
| 0 | Locomotion | Override | 无 | 1 |
| 1 | Action | Override | 无 | 0 |
| 2 | UpperBody | Override | UpperBodyMask | 0 |
| 3 | Additive | Additive | 可选 | 0 |

层级从低到高计算。

### 3.1 Locomotion

```text
Layer 0
持续播放 Idle / Walk / Run / Jump 等底盘动画
不会因为 Action 覆盖而停止
```

### 3.2 FullBody Action

```csharp
AnimancerLayer layer = animancer.Layers[1];
layer.IsAdditive = false;
layer.SetMask(null);
layer.Play(state, fadeDuration, fadeMode);
layer.StartFade(1f, fadeDuration);
```

Action 层权重为 1 时，最终表现完全使用 Action。

Locomotion 仍然满足：

```text
State Active
Timeline Running
Animation Playing
Animation Time Advancing
```

Action 结束：

```csharp
actionLayer.StartFade(0f, fadeOutDuration);
```

Locomotion 直接显露当前姿势，不重新播放、不从头恢复。

### 3.3 UpperBody

```csharp
AnimancerLayer layer = animancer.Layers[2];
layer.IsAdditive = false;
layer.SetMask(upperBodyMask);
layer.Play(state, fadeDuration, fadeMode);
layer.StartFade(weight, fadeDuration);
```

UpperBodyMask 通常包含：

```text
Spine / Chest / UpperChest
Neck / Head
Shoulder / Arm / Hand
```

通常排除：

```text
Root / Hips
Leg / Foot
```

下半身继续使用 Locomotion，上半身使用 UpperBody 动画。

### 3.4 Additive

```csharp
AnimancerLayer layer = animancer.Layers[3];
layer.IsAdditive = true;
layer.SetMask(optionalMask);
layer.Play(state, fadeDuration, fadeMode);
layer.StartFade(weight, fadeDuration);
```

```text
FinalPose = BasePose + Weight * AdditiveDeltaPose
```

适用内容：

```text
呼吸
后坐力
受击抖动
瞄准偏移
身体倾斜
蓄力振动
```

Additive Clip 必须正确配置 Reference Pose。

## 4. 播放规则

### 4.1 动画轨道

动画轨道是命令轨，不是持续采样轨。

```text
Timeline 到达动画轨道触发点
	-> 创建 AnimationPlayRequest
	-> CharacterAnimationController.Play(request)
	-> AnimancerLayer.Play(...)
```

常规 Tick 不重复发送相同播放请求。

### 4.2 同层切换

同一个 Animancer 层内播放新动画：

```csharp
layer.Play(nextState, fadeDuration, fadeMode);
```

Animancer 负责：

1. 新状态淡入。
2. 同层旧状态淡出。
3. 层本身保持当前目标权重。

### 4.3 跨层覆盖

高层 Override 不停止低层。

禁止：

```text
Action Enter -> Stop Locomotion Animation
```

正确行为：

```text
Action Enter -> Play Action Layer -> Fade Layer Weight To 1
Action Exit  -> Fade Action Layer Weight To 0
```

### 4.4 空动画状态

状态没有动画轨道或动画资源时：

1. 不发送播放请求。
2. 不自动停止其他层。
3. 是否淡出目标动画层必须由显式轨道命令或状态表现配置决定。

### 4.5 Hit Stop

Hit Stop 通过时钟速度控制，不通过每帧 Seek 实现。

```csharp
playback.SetSpeed(0f);
playback.SetSpeed(previousSpeed);
```

状态和动画是否同时冻结，由 Hit Stop 策略显式决定。

---

## 5. Root Motion

Root Motion 必须有唯一来源。

规则：

1. Locomotion 或 FullBody Action 可以申请 Root Motion。
2. UpperBody 和 Additive 禁止输出 Root Motion。
3. 同一时刻只能有一个 `RootMotionOwner`。
4. Root Motion 所有权由 gameplay/state 控制规则裁决。
5. 动画层权重不隐式决定 Root Motion 所有权。

```text
UpperBodyMask: Root/Hips 位移关闭
Additive: 不产生角色根位移
```

### 6.5 播放句柄

```csharp

{
	public readonly int Version;
	public readonly string OwnerStateId;
	public readonly AnimationLayerType Layer;

	public bool IsValid => Version > 0;
}
```

句柄用于防止旧状态的延迟停止命令误停新动画。

### 6.6 动画层运行时

```csharp
internal sealed class AnimationLayerRuntime
{
	public AnimationLayerType LayerType;
	public AnimancerLayer Layer;
	public AnimancerState CurrentState;
	public AnimationClip CurrentClip;
	public AnimationPlaybackHandle CurrentHandle;
	public float DefaultWeight;
}
```

### 6.7 动画控制接口

```csharp
public interface ICharacterAnimationController
{
	AnimationPlaybackHandle Play(in AnimationPlayRequest request);

	void Stop(
		AnimationPlaybackHandle handle,
		float fadeOutDuration);

	void SetLayerWeight(
		AnimationLayerType layer,
		float weight,
		float fadeDuration);

	void SetSpeed(
		AnimationPlaybackHandle handle,
		float speed);

	void Seek(
		AnimationPlaybackHandle handle,
		float localTime);
}
```

不保留常规 `SyncStateAnimation()`。

`Seek()` 只用于显式恢复和校正。

## 7. Animancer 实现骨架

```csharp
public sealed class AnimancerCharacterAnimationController
	: MonoBehaviour, ICharacterAnimationController
{
	[SerializeField]
	private AnimancerComponent _animancer;

	private readonly Dictionary<AnimationLayerType, AnimationLayerRuntime>
		_layers = new();

	private int _nextVersion;

	public AnimationPlaybackHandle Play(in AnimationPlayRequest request)
	{
		AnimationLayerRuntime runtime = GetLayer(request.OutputLayer);
		AnimationClip clip = LoadClip(request.ClipPath);
		object key = new AnimationStateKey(
			request.OutputLayer,
			request.OwnerStateId,
			request.ClipPath);

		AnimancerState state = runtime.Layer.GetOrCreateState(key, clip);
		state = runtime.Layer.Play(
			state,
			request.FadeDuration,
			request.FadeMode);

		state.Time = request.StartTime;
		state.Speed = request.Speed;
		runtime.Layer.StartFade(request.Weight, request.FadeDuration);

		AnimationPlaybackHandle handle = new(
			++_nextVersion,
			request.OwnerStateId,
			request.OutputLayer);

		runtime.CurrentState = state;
		runtime.CurrentClip = clip;
		runtime.CurrentHandle = handle;
		return handle;
	}
}
```

同一个 Clip 在不同 Animancer 层播放时，必须使用不同 key。

```text
Key = OutputLayer + OwnerStateId + ClipPath
```

禁止只使用 `AnimationClip` 作为全局 state key，避免同一个 `AnimancerState` 被移动到另一个层。

## 8. 状态侧调用规则

### 8.1 状态进入

```csharp
if (animationTrack.ShouldTrigger(previousTime, currentTime))
{
	playbackHandle = animationController.Play(request);
}
```

### 8.2 状态退出

```csharp
animationController.Stop(
	playbackHandle,
	animationTrack.FadeOutDuration);
```

如果该状态只是被更高动画层覆盖，不停止其自身动画。

### 8.3 状态恢复

```csharp
AnimationPlaybackHandle handle = animationController.Play(request);
animationController.Seek(handle, restoredLocalTime);
```

### 8.4 常规 Tick

```csharp
stateTimeline.Tick(deltaTime);
```

禁止：

```csharp
animationController.SyncStateAnimation(...);
```

## 9. 传统 Animator 对照方案

Animator Controller 层配置：

| Animator Layer | Blending | AvatarMask | 默认权重 |
|---|---|---|---:|
| Base | Override | 无 | 1 |
| FullBodyAction | Override | 无 | 0 |
| UpperBody | Override | UpperBodyMask | 0 |
| Additive | Additive | 可选 | 0 |

播放：

```csharp
animator.CrossFadeInFixedTime(
	stateHash,
	fadeDuration,
	layerIndex,
	normalizedStartTime);

animator.SetLayerWeight(layerIndex, weight);
```

淡出层：

```csharp
float weight = Mathf.MoveTowards(
	animator.GetLayerWeight(layerIndex),
	0f,
	deltaTime / fadeDuration);

animator.SetLayerWeight(layerIndex, weight);
```

传统 Animator 能实现相同层级关系，但动态技能动画需要：

1. 预建大量 Animator State。
2. 使用 AnimatorOverrideController。
3. 维护参数和 Transition。
4. 自己管理层淡入淡出。

当前项目是动态数据驱动技能，优先采用 Animancer。

### 9.1 Animancer 版本约束

当前项目随包 API 将以下能力标记为 Pro-Only：

```text
AnimancerLayer.SetMask(...)
AnimancerLayer.IsAdditive
任意 Layer Weight
部分非默认 Fade 参数
```

正式实施前必须确认 Runtime Build 使用 Animancer Pro。

如果项目只能使用 Animancer Lite，则备选方案为直接构建：

```text
AnimationLayerMixerPlayable
	Layer 0: Locomotion
	Layer 1: Action Override
	Layer 2: UpperBody + AvatarMask
	Layer 3: Additive
```

当前推荐方案仍为 Animancer Pro，不在项目内同时维护第二套 Playables 混合框架。

## 10. 实施顺序

```text
1. 扩展 AnimationLayerType
2. 增加 UnitAnimationLayerConfig
3. 配置 UpperBody AvatarMask
4. 单动画运行时改为 Dictionary<AnimationLayerType, AnimationLayerRuntime>
5. _animancer.Play 改为 animancer.Layers[index].Play
6. 删除 StateController 常规 Tick 动画同步
7. SyncStateAnimation 降级为显式 Seek
8. 实现 FullBody Action Override
9. 实现 UpperBody Mask Override
10. 实现 Additive Layer Weight
11. 明确 RootMotionOwner
12. 完成恢复、打断、Hit Stop 验证
```

验证用例：

```text
Run + FullBody Attack
Run + UpperBody Attack
Run + Additive Recoil
Action 覆盖期间 Locomotion 时间持续推进
Action 淡出后 Locomotion 无重播、无跳帧
状态中断后旧句柄不能停止新动画
非零时间恢复只执行一次 Seek
Hit Stop 无每帧硬校时
```

## 11. 最终约束

```text
State owns gameplay lifetime.
Timeline owns gameplay timing.
Animation owns presentation playback.
Animancer Layer owns pose composition.
Seek is recovery, not ticking.
Override hides lower layers, never stops them.
```

> 状态负责决定“做什么”，动画负责表现“看起来如何”。两者通过离散命令通信，不通过每帧时间绑定互相控制。
