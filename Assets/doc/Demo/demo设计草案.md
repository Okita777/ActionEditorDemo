arpgDemo
目标：使用自研的行为编辑器配置出期望的角色3c、技能逻辑和boss战。
核心：3c手感要好——重点是弹反和闪避的反馈
实施计划：1.先使用编辑器把玩家基础3c做好
2.做测试假人，验证ai逻辑结合编辑器的可能性
3.测试交互——攻击和受击反馈等打击感测试优化
4.设计战斗系统，确定战斗逻辑
5.设计玩家技能，扩充玩家角色行为逻辑——角色完全体
6.设计boss技能和ai逻辑，完成boss战。
7.(可选)qte系统和演出。
设计思路：
参考游戏：《绝区零》的闪避和弹刀和摄像机、《只狼》的弹刀、《影之刃》的交互
其他参考：《尼尔机械纪元》、《碧蓝幻想relink》、《湮灭之潮》、《影之刃零》、《战神》、《法环》、《之狼》。

概述：
1.  玩家基础有一套普攻连段+2个技能+格挡和闪避+移动系统。技能几乎没有cd,格挡和闪避的cd也较短（几乎没有）
2.  类似只狼：加入韧性条系统，并且加入心流系统：敌人每次未被格挡的攻击会削减玩家的韧性，当韧性条清零，玩家会倒地，并且心流也会减少1管，敌人韧性条清零也会倒地一段时间，作为极佳的输出窗口。玩家释放技能和攻击等不会影响韧性，只有被攻击才会被削减韧性。
关于心流：核心玩法中枢，心流共有3管，每一管3格。初始玩家有一管心流。玩家释放技能会消耗1格心流，随着心流的提升，玩家会解锁一些特殊玩法。心流会在玩家脱战3s后自动恢复（不足1管时）。当玩家击中敌人，也会累计一定的心流。2级以及上的格挡和闪避会极大的提高心流：2级的格挡会直接提升1格心流，3级的格挡会直接提升一管；2级的闪避会提升半格心流，3级的闪避会提升1格。
3.  核心体验：格挡和闪避——角色有常驻的格挡和闪避，boss也有格挡和闪避机制——和只狼里的逻辑类似——比如心中的一心，当玩家攻击一心时，一心会格挡符合格挡条件的攻击或者闪避一些招数。这里boss的攻击分为普通攻击、黄
光攻击和红光攻击——普通攻击被玩家格挡不会有特别的效果，玩家韧性不会削减。黄光攻击被玩家格挡或闪避就会触发2级的格挡效果：触发短暂时停，期间普攻和2个技能获得强化，在时停间隙攻击，停止时停。红光攻击会带来更长时间的时停，普攻和2个技能获得更强的强化，在攻击后解除时停。
4. 战斗手感：感觉上要做出只狼那种不停的刚刀的效果，并且在特定时机放大格挡的反馈——时停和反击，这里打算采用像绝区零那种夸张的镜头切换、抖动和时停效果以及顿帧效果。移动操作上，基本套用绝区零。
5. boss的设计：理想化设计：有2个阶段，粗略的感觉：半血进入二阶段——进入一段动画，最好加入qte系统，和玩家有一些交互。二阶段应该加入一些干扰因素，或者说变化，这里参考尼尔和影之刃这种（注：此处为可选项，可以不要，不在核心开发需求中）：比如boss会召唤多个机关：机关发射弹幕，玩家需要操作角色躲避并破坏机关之类的。boss不能像绝那样是一个没有智力的呆瓜，而是可以读指令的，根据玩家操作有反馈——会在某些情况下格挡，会闪避，这样会和玩家产生一些交互。
6. 总结下来，这是一款操作手感已绝区零为打底，战斗体验模仿只狼的高速arpgDemo,极大的放大格挡和闪避的反馈，将它和心流和技能融为一体，鼓励玩家通过格挡打出更炫酷的操作的一套战斗系统。战斗的难度不高，boss的上海不高，但是要想打出华丽和漂亮的操作，要保护好自己的韧性条，做好心流管理，就可以打出酣畅淋漓的感觉。
